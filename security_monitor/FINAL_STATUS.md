## 📊 What Gets Scanned

When you run a scan on a target:

```
1. DNS RESOLUTION
   ✓ Resolves domain to IP address
   ✓ Detects CDN (Cloudflare, Akamai, AWS, etc.)
   ✓ Checks CNAME records

2. PORT SCANNING
   ✓ Discovers open TCP ports
   ✓ Identifies services (HTTP, HTTPS, SSH, etc.)
   ✓ Gets service versions

3. VULNERABILITY ANALYSIS
   ✓ Checks against 20+ rules
   ✓ Looks for misconfigurations
   ✓ Identifies security issues

4. RISK ASSESSMENT
   ✓ Calculates 0-100 score
   ✓ Assigns risk level: LOW / MEDIUM / HIGH / CRITICAL
   ✓ Provides breakdown

5. RECOMMENDATIONS
   ✓ Generates hardening guides
   ✓ Step-by-step fixes
   ✓ Difficulty & impact ratings

6. REPORT GENERATION
   ✓ Creates detailed report
   ✓ Saves to reports/ folder
   ✓ Stores in database
   ✓ Logs to audit trail
```
