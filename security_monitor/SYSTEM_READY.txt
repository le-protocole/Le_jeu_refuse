## Workflow (What Gets Scanned)

```
Target URL/IP
      ↓
[1] DNS Resolution → Resolve to IP, detect CDN
      ↓
[2] Port Scanning → Find open TCP ports, identify services
      ↓
[3] Analysis → Check 20+ vulnerability rules
      ↓
[4] Risk Scoring → Calculate 0-100 score
      ↓
[5] Recommendations → Generate hardening guides
      ↓
[6] Report Generation → Create JSON/HTML/TXT
      ↓
[7] Database Storage → Save for historical tracking
```
